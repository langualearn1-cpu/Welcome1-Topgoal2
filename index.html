الخطوة الثانية: إنشاء المستودع ورفع الملف

المستودع (Repository) هو المجلد السحابي لحفظ مشروعك.

📁

اتبع الخطوات البسيطة التالية على موقع GitHub.com:

Create a new repository github.com/new
langualearn1-cpu / my-quiz-lesson
Public (عام) ⚠️ Anyone on the internet can see this repository. (إجباري لـ GitHub Pages المجاني)
Add a README file ✓ يجعل المستودع جاهزاً فوراً لرفع الملف بالسحب والإفلات.

طريقة رفع ملف index.html:

  1. اضغط من أعلى المستودع على زر Add file.
  2. اختر Upload files.
  3. اسحب ملف index.html وأفلته في المربع.
  4. انزل لأسفل واضغط الزر الأخضر: Commit changes.

الخطوة الثالثة: تفعيل خادم GitHub Pages

هذه الخطوة تطلب من خادم GitHub تحويل كودك إلى موقع حي يعمل بالمتصفح.

⚙️

داخل صفحة المستودع نفسه، نفذ هذه النقرات الثلاث بالترتيب:

📁 <> Code Issues Pull requests Actions ⚙️ Settings (1. اضغط هنا)
القائمة الجانبية اليسرى: General ➔ 📄 Pages (2. اضغط هنا)
Branch: غيّر من None إلى:
main ✓ / (root)
  1. اضغط على Settings (الإعدادات ⚙️) من الشريط العلوي للمستودع في أقصى اليمين.
  2. من القائمة الجانبية في اليسار، انزل واضغط على Pages.
  3. تحت قسم Branch، غيّر من None إلى main، ثم اضغط على زر Save الأزرق.

⚠️ أهم 3 أخطاء تمنع ظهور الرابط وكيف تحلها فوراً:

🚫 1. خطأ 404 Not Found

السبب: اسم الملف ليس index.html بالضبط، أو أنك استعجلت ولم تنتظر دقيقة حتى يكتمل البناء.

✓ الحل: أعد تسمية الملف إلى index.html وانتظر دقيقة.
🔒 2. المستودع خاص (Private)

السبب: ميزة GitHub Pages المجانية تعمل فقط عندما يكون المستودع عاماً (Public).

✓ الحل: من Settings غيّر الخصوصية إلى Public.
🔄 3. التعديلات لا تظهر

السبب: ذاكرة التخزين المؤقت للمتصفح (Cache) تحتفظ بالنسخة القديمة.

✓ الحل: اضغط Ctrl + Shift + R للتحديث الإجباري.
